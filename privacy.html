Privacy policy

YouTube Library Tools · Last updated 8 October 2026

This policy covers YouTube Library Tools (the "application"), an internal tool operated by Jaman Properties Ltd. The application is used only by the company's director, on their own Google account.

What the application accesses

With the account holder's permission, given through Google sign-in, the application uses the YouTube Data API to:

  • read the list of playlists in the account and the videos in them;
  • create playlists, add videos to playlists and rename playlists.

It does not access email, contacts, files, payment details or any other Google service, and it never deletes content.

How data is used and stored

  • Playlist and video information is used only to organise the account holder's own playlists, at their request.
  • The sign-in credential (an OAuth refresh token) is stored privately in the account holder's own configuration and is not shared.
  • No data is sold, shared with third parties or used for advertising.
  • Video content may be sent to Google's Gemini API for summarisation, under the account holder's own Google account. No other third party receives it.

Google API Services

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also relies on YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions.
